Air Quality Monitor

November 2025

This is an Air Quality Monitor which I made when Delhi's Air Quality hit a staggering high of 900 which is much more than the generally conisdered HAZARDOUS limit of 300. This is project includes a MQ135 Gas Sensor which provides a not very accurate but good enough AQI level which is displayed on a 128x64 OLED Display. All of these components are controlled by an Arduino Nano which is powered by 2 rechargable batteries. All of this is enclosed in a 3D Printed case designed by me.
